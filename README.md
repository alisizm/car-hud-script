## 🇬🇧 English Description

### 📖 Overview
Designed to give your server a modern look, **Alisizm Advanced HUD** combines minimalism with advanced functionality. Built on a high-performance React/Vite framework, it delivers the smoothest UI experience without impacting your in-game FPS. 

### ✨ Key Features
*   **11 Unique Styles:** Choose your favorite look from 11 unique design presets, easily accessible in-game via the `/carhud` command.
*   **Modern Aesthetics:** Equipped with the sleek and elegant Geist font family alongside fully customized digital indicators.
*   **Comprehensive Vehicle HUD:** A detailed dashboard that provides vital information at a glance, including seatbelt status, engine check lights, fuel levels, and turn signals.
*   **Highly Optimized:** Minimized assets and a clean React/Vite code structure ensure extremely low CPU/GPU usage, even during peak server hours.
*   **Responsive UI:** Fully compatible with all screen resolutions, ensuring a seamless, non-overlapping look across different monitors.
*   **Simple Configuration:** Easily adjustable settings via the `config.lua` file to perfectly fit your server's specific needs.

### 📦 Package Includes
*   Fully optimized HUD scripts (Including all 11 Styles).
*   Customized, high-quality vehicle status icons.
*   Built-in Geist font family integration.
